UBC FRESH · FABLE Calculator

Scenarios, outputs, and evidence in one local portal.

Prepare a matching workbook and generated model, run named selection controls, read headline indicators and output tables, and compare saved results. Every value comes from the generated model; this portal never recomputes a FABLE result.

Presentation, not a second model

The service reads the generated model and the artifacts the notebook workflow already produces.

Local by default

A non-loopback bind requires --allow-remote. There are no accounts.
